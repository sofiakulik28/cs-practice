# Мои заметки
Рабочая папка (Working Directory) — это папка на моем компьютере, где я редактирую файлы прямо сейчас.
Индекс (Staging Area) — это промежуточная область, куда я добавляю файлы перед сохранением (командой git add).
Коммит (Commit) — это сохранение текущего состояния файлов в истории Git.
Git — это локальная программа для контроля версий, работающая на компьютере.
GitHub — это облачный сервис для хранения репозиториев Git и совместной работы.
git status — показывает состояние файлов (какие изменены, какие в индексе).
git diff — показывает разницу между рабочей папкой и индексом.
git diff --staged — показывает разницу между индексом и последним коммитом.
Ветка (branch) — это отдельная линия разработки, позволяющая вносить изменения, не затрагивая основную ветку.
При новом коммите указатель ветки сдвигается на этот коммит.
Слияние (merge) — это объединение изменений из одной ветки в другую.
